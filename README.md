# Jessica AI

Jessica is a personal AI assistant inspired by FRIDAY from Iron Man.

## Features

- 🎙️ Natural voice responses using ElevenLabs
- 👏 Double clap wake detection
- 🎵 Automatic AIMP music playback
- 💻 Workspace automation
- 🌐 Opens ChatGPT and TradingView
- 🏋️ Health intelligence
- 📊 Modular architecture for future expansion

## Planned Features

- Weather briefing
- Calendar integration
- GitHub activity
- Market updates
- Email summaries
- Voice commands

## Tech Stack

- Python
- ElevenLabs
- NumPy
- SoundDevice
- OpenPyXL
